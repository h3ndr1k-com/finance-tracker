# Ledger

Local, private, multi-currency personal finance tracker. No accounts, no cloud, no build step — all data stays in your browser (IndexedDB).

**Serve it** (service workers don't run from `file://`): `python3 -m http.server 8000` in this folder, open `http://localhost:8000`, then install via the browser's "Add to Home Screen" / install prompt. Works fully offline after first load. Empty on first open — click **Load sample data** (or Settings → Load sample data) to explore with a 3-month multi-currency dataset, then **Wipe all data** and drop your real CSVs. **Jars** tab = T. Harv Eker allocation buckets (income auto-splits by %, editable); **Recurring** panel on Overview auto-detects subscriptions and flags price hikes; base currency defaults to CAD (change in Settings). **Export CSVs:** from your credit card's web portal use "Download transactions/statement → CSV"; from Wealthsimple use Activity → Export (or Statements → CSV) per account — then drag the files into the app and confirm the column mapping once per format. **Exchange rates:** open ⚙ Settings and enter EUR-per-unit rates for USD/CAD (e.g. USD 0.92) — all totals convert to your base currency through these manual rates; edit them anytime and every view recalculates.
